## 先说核心区别：包月买服务 vs 按量买模型

一句话版本：

> 订阅是固定月费，换来一套开箱即用的编码智能体，用量跟着套餐走；API 是按 token 付费，用多少算多少，适合低频使用，或者把 Codex 的能力集成进自己的工具。

订阅付的是“产品”：终端 CLI、IDE 插件、云端任务、GitHub 代码审查一整套，ChatGPT 账号登进去就能干活，不用操心计费。

API 给的是“模型”：你得自己写代码调用，或者套在 code CLI 这类现成工具里用，账单跟着 token 数走，用得少花得少，用得多也没人拦你。

## Codex 到底是个什么产品

补一点背景，方便理解后面为什么是这套计费结构。Codex 最早在 2025 年 4 月以开源命令行工具（code CLI）的形态上线，5 月推出网页版，之后 OpenAI 把它统一成了一个产品：用你的 ChatGPT 账号串起所有入口，本地和云端之间切换任务不会丢上下文。

现在 Codex 覆盖这些地方：

- **终端**：code CLI，开源，可以在命令行里直接贴截图、线框图讨论设计，复杂任务会用待办清单追踪进度
- **IDE**：官方扩展支持 VS Code、Cursor 和各类 VS Code 分支，能利用你打开的文件和选中的代码，提示词可以写得更短
- **云端**：网页端派任务，Codex 自己扫描 setup 脚本搭环境，按需联网装依赖，跑完把结果和截图附在任务里
- **GitHub**：给仓库开启后，PR 从草稿转为 ready 时自动审查，也可以手动 @codex review，还能加限定条件，比如专查安全漏洞或过时依赖
- **手机**：ChatGPT iOS app 里也能接上 Codex

模型层面，GPT-5-Codex 是在 GPT-5 基础上针对智能体编程再训练的版本：从零搭项目、加功能写测试、调试、大规模重构、代码审查都是它的主场，对 AGENTS.md 指令的遵循也更好。官方的建议很明确：只把它用在 Codex 或类似 Codex 的编程环境里，别当通用模型。

一个容易混淆的点顺便提一下：搜“Codex API”时可能会看到一家叫 codex.io 的服务，那是做加密货币链上数据查询的 GraphQL API，和 OpenAI 的编码助手只是重名，别点错。

## 订阅方式：登录就能用，用量看套餐

Codex 包含在 ChatGPT Plus、Pro、Business、Edu、Enterprise 五类套餐里，不需要单独购买。差别在用量：

- Plus、Edu、Business 的席位，官方定位是支撑**每周几次专注的编码会话**
- Pro 支撑**一整个工作周、多个项目并行**的强度
- Business 可以加购 credits，让开发者超出自带额度继续用
- Enterprise 是共享 credit 池，开发者用多少付多少

订阅版里，GPT-5-Codex 是云任务和代码审查的默认模型。代码审查值得多说两句：它和静态扫描工具的思路不一样，会把 PR 描述的意图和实际 diff 对上，梳理整个代码库和依赖，还会跑代码和测试来验证行为。OpenAI 自己的 PR 目前大部分由它先过一遍，每天能抓出几百个问题。官方也提醒过，它的定位是给人类审查者减负的补充，替代不了人。

入口体验是订阅最大的优势。不用管 key，不用管账单，登录 ChatGPT 账号，CLI、IDE、网页、GitHub 全部打通。安全上默认跑在沙箱里、关闭网络访问；CLI 提供三档审批级别：只读需确认、自动（工作区内放行、工作区外要批准）、完全访问。云端任务还有容器缓存加速，新任务和后续任务的完成时间中位数砍掉了 90%。

唯一的短板是额度。如果你每天大部分时间都在跑大型重构，Plus 档的周额度会比较紧，官方给重度用户准备的答案是 Pro。

## 常见问题

**不订 ChatGPT，只用 API 也能用 Codex 吗？**

能。GPT-5-Codex 已经开放 API，在 Responses API 里按 token 计费；开源的 code CLI 也支持直接填 API key 运行。

**API 按量计费大概花多少钱？**

取决于任务量。可以参考两个锚点：codex-mini-latest 是输入 $1.50、输出 $6 每百万 token；GPT-5-Codex 与 GPT-5 同价。简单任务上 GPT-5-Codex 的 token 消耗比 GPT-5 低不少，轻度使用的账单往往比想象中省。

**订阅额度用超了怎么办？**

Plus 档等额度刷新；Business 可以加购 credits；Enterprise 本身就是共享池，按实际用量扣费。

**GPT-5-Codex 和 GPT-5 有什么区别？**

前者是针对智能体编程场景再训练的版本，更听指令、代码质量更高，但官方明确不建议在通用场景使用。写代码选 GPT-5-Codex，通用任务继续用 GPT-5。
